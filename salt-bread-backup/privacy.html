개인정보처리방침

  • 이 앱(salt-bread-backup)은 소유자 본인만 사용하는 개인 백업 도구입니다.
  • Google 계정 권한은 소유자 본인의 Google Drive에 백업 파일을 업로드하고 관리하는 데에만 사용합니다.
  • 다른 사용자의 데이터를 수집하지 않으며, 어떤 데이터도 제3자에게 제공·판매·공유하지 않습니다.
  • 인증 토큰은 소유자의 개인 컴퓨터에만 저장됩니다.
  • Google API에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

Privacy Policy

  • This app (salt-bread-backup) is a personal backup tool used only by its owner.
  • Google account access is used solely to upload and manage backup files in the owner's own Google Drive.
  • No data from other users is collected, and no data is provided, sold, or shared with any third party.
  • Authentication tokens are stored only on the owner's personal computer.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
